# SkillMint 产品 Epic 梳理

> 2026-09-05 定稿。基于真机逐页盘点 + 两轮 grill-me 访谈收敛。
> 原则：能力不用太多，每个 epic 一句话能讲清。

## 定位语

**SkillMint 是一台个人成长飞轮——记录每一次 Agent 协作，沉淀为可复用的资产。**

本地优先、默认离线、单机单用户。三个 epic 就是飞轮的三段：

| Epic | 一句话 | 回答的问题 |
|---|---|---|
| E1 管好技能资产 | 装得上、看得清、收得拢 | 我的技能在哪、怎么管？ |
| E2 看清投入产出 | 把协作变成可度量的数据 | 我和 Agent 协作得值不值？ |
| E3 越用越富 | 从使用数据里长出新资产 | 用得越多，为什么越值钱？ |

---

## E1 管好技能资产

让散落在十几个 agent 目录里的技能，装得上、看得清、收得拢。安装状态由 `npx skills` CLI 持有，app 是它的 GUI。

### F1.1 技能库浏览与检索
- S1.1.1 按全部 / 已安装 / Hub / 未管理筛选，支持项目上下文切换（仅全局 / 指定项目）
- S1.1.2 查看单个技能详情（描述、支持的 agent、来源与状态）

### F1.2 安装生命周期（npx skills 驱动）
- S1.2.1 一键把技能安装到我选定的多个 agent
- S1.2.2 检测并修复失效技能（基线：索引 220 · 失效 43）
- S1.2.3 开启远程功能后，从 skills.sh 浏览并安装远程技能（发现页，默认离线不入口）

### F1.3 私有 Hub
- S1.3.1 在 Hub 新建自制技能（全局 Hub 或项目 Hub）
- S1.3.2 把散落各 agent 目录的技能收集 / 复制进 Hub（基线：未管理 130 个待归拢）

### F1.4 技能集
- S1.4.1 把常用技能打包成组合，一键应用到项目或导出分享

### F1.5 Agent 目录（同步目标）
- S1.5.1 查看各 agent 的 skills 目录路径与技能数，支持重新扫描（基线：HARNESS 组 13 个 agent）
- S1.5.2 启用 / 禁用某 agent 作为安装目标

---

## E2 看清投入产出

把每一次协作变成可度量的数据：用量、成本、质量。

### F2.1 采集引擎（数据地基）
- S2.1.1 从本地 Agent 会话记录采集使用数据，采集源与规则可配置
- S2.1.2 定时任务自动采集；后台任务可查、失败可重试（任务中心）
- S2.1.3 待确认 / 低置信队列：人工复核保证数据质量

### F2.2 洞察仪表盘
- S2.2.1 今天页：昨日协作摘要（会话 / token / 最活跃项目）+ 连续记录 + 资产引用速览
- S2.2.2 用量总览四卡：会话数 / 总 Token / 估算成本 / 质量评分，含环比
- S2.2.3 成本画像：fresh / 缓存命中率、模型与工具调用、计费构成、按平台分布
- S2.2.4 高消耗会话警告（Top 10%，疑似上下文膨胀）

### F2.3 项目维度洞察
- S2.3.1 项目按 token / 会话排名，支持扫描与查看单项目详情

### F2.4 工作记忆报告
- S2.4.1 每日摘要：当天协作的规则版日报
- S2.4.2 周报：每周一早晨自动生成，可立即生成预览

---

## E3 越用越富

飞轮闭环：使用数据 → 发现模式 → 长出新资产。

### F3.1 重复模式 → 沉淀 Skill
- S3.1.1 检测重复 Prompt 模式并给出"建议沉淀为 Skill"（基线：单模式重复 3766 次）
- S3.1.2 从建议一键进入沉淀流程，生成技能草稿进 Hub

### F3.2 收件箱（每日发现，低配承诺）
- S3.2.1 每天采集完成后，把当日重复模式、沉睡技能汇总进收件箱（规则版；AI 配置后升级为精选版）

### F3.3 资产关系可视化
- S3.3.1 知识图谱展示技能与概念的关系，提示高连接概念与沉睡技能（基线：200 节点 · 15 关系）

---

## 验收口径：规则版打底，AI 增强

所有依赖 AI 生成的 story（S2.4.x、S3.2.1）验收标准统一为：
**未配置 AI 模型时，规则版（纯数据汇总）可用；配置后升级为 AI 生成版。**
飞轮不因没配模型而停转。

## 现有页面 → Epic 映射

| 导航页 | 归属 |
|---|---|
| 今天、洞察档案、项目 | E2 |
| 收件箱、知识图谱 | E3 |
| Skill 库、Agent 目录、发现 | E1 |
| 周报、每日摘要 | E2（合并为「工作记忆报告」） |
| 设置、任务中心 | 横切 enabler |
| 待确认、低置信 | E2（采集引擎的复核队列） |

## 横切 enablers（不占 epic）

- **本地优先基座**：默认完全离线；"远程功能"显式开关；遥测默认关闭
- **设置中心**：Node 运行时、skills CLI 规格、搜索镜像（SKILLS_API_URL）、代理注入（China 加速）
- **数据管理**：本地 SQLite（可重建索引缓存）、导出、设备 ID 隔离
- **任务基建**：定时任务 + 任务中心（采集、报告等后台作业复用）
- **AI 分析（可选）**：ACP / 多模型 / Embedding 配置，为"AI 增强"提供开关

## Later（明确不承诺）

- 任务驱动推荐（按任务推荐 Skill 组合）
- 成本杠杆、自定义卡片、Prompt 语义 · 协作画像
- 收件箱 AI 精选（先做规则版汇总）
- Hub → 远程仓库的发布与分发
- **OpenViking 融入**（飞轮的外置上下文引擎，只增强不替代）——设计已定稿，见 `docs/openviking-integration.md`，按其 P0-P4 路线后续实现
